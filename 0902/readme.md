## 1. 웹(Web)의 기본 개념과 작동 구조

* **웹 (World Wide Web, WWW):** 인터넷을 활용하여 거미줄처럼 연결된 정보 소통 망입니다.
* **인터넷 vs 웹:**
  * **인터넷:** 1969년 미 국방성(ARPA)에서 시작된 전 세계 컴퓨터를 연결한 물리적 네트워크 망입니다.
  * **웹:** 1990년 물리학자 팀 버너스리(Tim Berners-Lee)가 개발한 서비스로, 인터넷이라는 네트워크 위에서 동작하는 정보 공유 시스템입니다.

### 🖥️ 웹 서버와 웹 클라이언트
* **웹 서버 (Web Server):** 웹 사이트를 탑재하고 웹 문서(HTML), 이미지, 동영상 등을 저장 및 관리하며 클라이언트의 요청 시 이를 전송합니다.
* **웹 클라이언트 (Web Client):** 사용자가 사용하는 웹 브라우저로, 웹 서버에 데이터를 요청하고 응답받은 결과를 화면에 출력해 줍니다.

## 2. 웹 페이지를 구성하는 3요소

웹 페이지는 기능별로 3가지 요소가 분리되어 개발됩니다:

| 구성 요소 | 역할 및 설명 |
| :--- | :--- |
| **HTML (구조)** | 웹 페이지의 기본 뼈대와 텍스트, 이미지 등의 콘텐츠를 정의하는 표준 언어입니다. |
| **CSS (모양/스타일)** | 글꼴, 색상, 배치 등 웹 페이지의 외관과 레이아웃을 제어합니다. |
| **JavaScript (행동/동작)** | 사용자 마우스 클릭 이벤트 처리, 동적 화면 변경 등 반응형 인터랙션을 구현합니다. |

## 3. HTML5의 출현 배경 및 핵심 특징

### 📌 출현 배경
* **비표준 기술의 난립:** Active-X, 플래시 등 플러그인 의존으로 인한 브라우저 간 심각한 비호환성 발생.
* **모바일 단말기 확산:** PC 외에도 스마트폰, 태블릿 등 다양한 인터넷 접속 기기가 등장함.
* **범용 웹 표준 필요:** PC와 모바일 기기 모두에서 동일하게 작동하는 새로운 통합 규격이 필요해짐.

### ✨ HTML5의 특징 및 의의
* **플러그인 배제:** Active-X나 플래시 없이 오디오, 비디오, 애니메이션, 게임 등을 자체 재생 가능.
* **멀티 플랫폼 지원:** OS나 기기(PC, 모바일, 스마트 TV 등) 종류에 관계없이 동일한 실행 환경 보장.
* **웹 애플리케이션 지원 API 표준화:**
  * 오디오/비디오 태그, Canvas / SVG (그래픽)
  * Web Storage / IndexedDB (로컬 저장소)
  * File I/O, Geolocation (위치 정보 API), Web Socket, Web Worker 등 지원

## 4. HTML5 문서 작성 및 디버깅 환경

### 🛠️ 문서 작성 도구
* **텍스트 편집기:** Sublime Text, Atom, VS Code 등 (작성 후 `.html` 파일로 저장).
* **WYSIWYG 편집기:** Dreamweaver 등 화면을 보며 작성할 수 있는 편집기.
* **문자 인코딩:** 한글 깨짐 방지를 위해 HTML, CSS, JavaScript 파일 모두 **UTF-8** 코드로 저장이 필수적입니다.

### 🐛 디버깅
* 크롬 등 웹 브라우저의 **개발자 도구 (F12)**를 활용하여 소스 코드 검사, 콘솔 오류 확인 및 디버깅을 수행합니다.
